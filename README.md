# QUESTION5
1. HTML:
o A webpage with a table to display product sales details (Product ID, Product
Name, Quantity Sold, Price).
o A button labeled "Add Sale" to trigger the prompt for entering new sales details.

2. CSS:
o Style the table and button for a clean and professional look.
o Add hover effects to the button and ensure the table layout is responsive.

3. XML:
o Use XML to store the product sales data, including the following fields:
▪ Product ID
▪ Product Name
▪ Quantity Sold
▪ Price

4. JavaScript:
o When the "Add Sale" button is clicked:
▪ Prompt the user to enter the sales details (Product ID, Product Name,
Quantity Sold, Price).
▪ Validate inputs (e.g., no fields should be empty, and numeric fields should
be valid numbers).
▪ Update the XML database with the new entry.
▪ Display the updated sales data in the table.

Expected Output:
1. Initial State: An empty table with columns for Product ID, Product Name, Quantity
Sold, and Price.
2. Add Sale Button: Clicking the button prompts the user to enter details for a new product
sale.
3. Validation: If inputs are invalid or missing, an alert is shown.
4. Updated Table: Valid inputs add a new row to the table and update the XML database.
